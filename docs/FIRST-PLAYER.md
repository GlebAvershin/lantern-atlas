# Первая самостоятельная партия

Цель наблюдения — понять, в какой момент новому игроку становится трудно предсказать результат нажатия и понять работу дальнего реле. Для сессии нужен человек, который прежде не видел решения. [Открыть игру в браузере](https://glebavershin.github.io/lantern-atlas/)

**Задание игроку.** «Попробуйте зажечь все маяки. Играйте как обычно. Если что-то удивит, скажите, чего вы ожидали». Используйте чистый браузерный профиль или приватное окно. Ведущий отмечает версию игры, тип ввода и размер окна. Первые три минуты дайте игроку действовать самостоятельно. Затем спросите, что он ожидал от последнего нажатия. Когда дойдёт до карты с ромбами, попросите перед следующим ходом показать, какие станции изменятся. Если игрок остановился раньше, зафиксируйте карту и причину.

| Поле локальной заметки | Что записать |
| --- | --- |
| Сессия | Обезличенный номер, дата, коммит, устройство и карта |
| Наблюдаемое действие | Что игрок нажал, что ожидал увидеть, что произошло, когда понадобилась подсказка |
| Обратная связь | Одна короткая цитата с разрешения игрока |
| Решение разработчика | Выбранная проблема, изменение, ссылка на diff, заранее сформулированный признак успеха |
| Повтор | Новый коммит, сопоставимая карта, самостоятельное действие, результат и влияние знакомства с механикой |

Для одного наблюдения достаточно описать конкретное затруднение и повторную проверку. Сохраните отдельную строку, если проблема осталась. Публикуйте обезличенный результат с согласия участника.
